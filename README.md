# grid

un sitio personal minimalista. no es un portafolio, no es un blog. es un espacio donde dejo lo que hago y lo que me interesa.

## qué hay

- una sección de proyectos con links a lo que estoy armando (hackpads, scripts, cosas raras)
- una sección de intereses (hardware, teclados, código)
- diseño oscuro, monospace, sin frameworks pesados

## stack

astro + css puro, deployado en github pages
